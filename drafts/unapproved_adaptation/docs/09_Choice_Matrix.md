# 09｜完整选项与分支矩阵

> 本表是 [08_Full_Game_Script.md](08_Full_Game_Script.md) 的实现依据。历史真相永不因选择改变；选择只改变证据质量、人物信任、玩家能否完成证明及最终处置。

## 变量缩写

| 缩写 | 含义 |
|---|---|
| ET | Edward Trust，爱德华信任值 |
| WT | Witness Trust，证人总体信任 |
| TA | Timeline Accuracy，时间线完整度 |
| IE | Independent Evidence，独立证据数量 |
| CT | Contaminated Testimony，被污染证词数量 |
| IM | Invitation Mark，邀请函暗记 |

## 第六章交叉质询题（不计入十项关系选择）

题目：十二份证词最关键的共同缺陷是什么？

- A 外貌描述不一致：疑点，但光线和角度可解释。
- B 没有任何证词完成独立身份确认：正确，解锁最终证据提交。
- C 日期并非同一晚：正确的中间结论，但只能证明证词被重排。

## 结局安全规则

1. 任何选项都不能改变 `truth.august_dead=true` 与 `truth.algernon_alive=true`。
2. C08-A 只能提高爱德华证言可信度，不能设置 `independent_id_confirmed=true`。
3. 证词污染影响“能否证明”，不让证人的真实经历凭空变化。
4. 玩家可在章节结束前补做遗漏检查，但补查证据的独立性或时间成本较差。
5. END 05 在方案 A 之后增加邀请者谜题，不推翻身份与死亡真相。
