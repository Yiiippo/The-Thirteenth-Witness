# 第二部分：创作者必须知道的完整真相

以下内容为完整剧透，玩家不能在开局看到

为了避免故事最后变成临时编造的反转，这里先固定整个案件的真实情况。

## 真相一：十二个人确实见过一些东西，但没有人真正见过爵士

阿尔杰农·维尔爵士长期患有一种会影响记忆与判断的神经系统疾病。

过去两年，他已经很少亲自出现在公众面前。

庄园里的人逐渐习惯通过不同方式确认他的存在：

- 通过留声机听到他的声音。
- 通过书房的玻璃反射看到他的身影。
- 通过管家传递他的书面指示。
- 通过爱德华转述他的决定。
- 通过信件确认他的意见。

而庄园的主人身份和权威，逐渐变成了一个由声音、文字、习惯和他人记忆共同维持的形象。

每个人都认为自己认识爵士。

但他们认识的，其实是自己心中的爵士。

## 真相二：爵士的死亡不是整起事件的核心

爵士确实已经死亡，但玩家最初发现的尸体并没有经过正式身份鉴定。

他真正的死亡时间与所有人的证词都存在冲突。

本作最重要的谜题不是“谁杀了爵士”，而是：

玩家如何证明那个死去的人就是阿尔杰农·维尔？

## 真相三：第十三位证人是谁？

第十三位证人是爱德华。

但这不是简单的“爱德华就是凶手”。

二十年前，爱德华还是一个五岁的孩子。

他曾经参加过一场由父亲安排的家庭实验。

实验要求十二名成年人分别描述一个人的身份特征。

而爱德华是唯一一个真正见过那个人本人、能够指出身份错误的人。

后来，这份记录被隐藏。

爱德华一直不知道自己为什么会出现在那份旧档案里。

他委托艾薇调查，实际上也是想知道自己童年记忆中究竟发生过什么。

## 真相四：最终的核心反转

庄园里所有人都没有说谎。

他们确实见过一个被称为“阿尔杰农·维尔”的形象。

但在不同时间、不同地点，他们见到的可能是：

- 一段录音。
- 一封信。
- 一个背影。
- 一个人的转述。
- 一张被重新摆放的照片。

“阿尔杰农·维尔”在这座庄园里，逐渐变成了一种被所有人共同维护的身份，而不再是一个可以被所有人独立确认的具体人物。

这就是本作最核心的谜题。

注意：这只是身份诡计，不是说爵士从来不存在。正式结局仍然必须通过身体特征、私人记录和物证确认尸体身份。

# 第四部分：最终的真相

完整真相解锁

这一部分是创作者需要固定的最终谜底。

为了让整个故事真正闭环，我建议将真正的事件时间线设定如下。

| 时间   | 实际发生的事情                       |
| ---- | ----------------------------- |
| 二十年前 | 维尔家族进行了身份识别实验，爱德华是第十三位证人      |
| 三个月前 | 卢西安来到庄园，寻找失踪的家族手稿             |

| 一个月前 | 塞西莉亚开始销毁私人信件                  |
| 三天前  | 爱德华最后一次亲自见到父亲                 |
| 两天前  | 阿尔杰农因疾病死亡                     |
| 案发当晚 | 庄园里的人分别通过声音、文字、影像等信息，认为爵士仍然存在 |
| 午夜   | 阿瑟发现书房中的尸体，向爱德华报告             |

这里要揭开的真正秘密有三层。

第一层：庄园里存在两个人的身份混淆。

阿尔杰农确实有一位双胞胎兄弟奥古斯特。

奥古斯特曾经在维尔家族生活，但因为家族内部的财产与身份问题，他的存在被逐渐从正式记录中抹去。

二十年前的实验，实际上就是为了证明：

当一个人拥有另一个人的名字、衣着、习惯和社会关系时，旁人还能不能分辨他们？

第二层：十二个人并不是在同一晚见到爵士。

他们所描述的事情发生在不同时间。

邀请函故意使用模糊措辞，让他们将过去几个月内发生的事情全部理解为案发当晚的经历。

没有人撒谎。

但是他们对时间的理解被错误引导了。

第三层：书房里的尸体并不能被直接认定为爵士。

这是全游戏最重要的未解谜团。

奥古斯特和阿尔杰农曾经互换过身份。

旧照片、医疗记录、遗嘱以及家族登记册都出现过修改痕迹。

所以，玩家必须决定是否相信爱德华童年的记忆，是否接受朱利安的医学判断，以及是否将这件事交给外部调查。

而且，这里有一个重要的限制：

我们不能在没有正式鉴定的情况下直接宣布尸体就是奥古斯特。

真正的真结局需要通过独立的身份鉴定确认尸体身份，其他结局则保留部分疑点。

# 最后：我对这版剧本还有一个重要的质量要求

目前这份文档已经把人物、章节、选择、主要分支和结局整理出来了，但我不建议直接把它当成最终定稿投入制作。

原因是：最后的双胞胎身份诡计、尸体身份和十二份证词之间，还需要一次严格的逻辑校验。

尤其需要解决三个问题：

1. 奥古斯特为什么会出现在庄园？他与阿尔杰农的关系如何被隐藏？
2. 十二个人分别掌握了哪些信息？他们为什么会将不同时间的经历理解成同一晚？
3. 艾薇最终凭什么证明尸体身份？需要什么可以被玩家提前发现的客观证据？

这些问题必须在正式开发前全部确定。不能只依靠爱德华回忆起来的一句话来揭晓谜底。

我建议将爱德华的真实身份、奥古斯特的存在，以及艾薇收到的邀请函作为整款游戏的三条主线。

这样，第一周目玩家看到的是一桩奇怪的庄园死亡案件；第二周目重新游玩时，则会发现自己在第一章就已经接触过真正的答案。

这才是我希望《第十三位证人》最终达到的效果。
