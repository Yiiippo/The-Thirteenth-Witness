# 03｜线索、证词与推理闭环

> **状态：A2 案件修订的实施参考稿。**  
> 正式五组证据及推理关系以 [10B_Scheme_A_Final_Case_Setting.md](10B_Scheme_A_Final_Case_Setting.md) 为准；新增内容必须先登记来源。

## 谜面与答案

玩家初见：书房中“阿尔杰农”的尸体、十二段似乎关于同一位爵士的回忆、署名“第十三位证人”的邀请函。

最终答案：尸体是奥古斯特；阿尔杰农策划骗局后以奥古斯特身份逃离；证词均真实，但发生在不同日期、通过不同媒介并指向不同兄弟；爱德华是 1877 年隐藏的第十三位证人。

## 邀请函

> 致曾经见过维尔先生的诸位  
> 在过去的岁月里，你们都曾以不同的方式见过维尔先生。有人见过他的面容，有人听过他的声音，有人收到过他的信件。如今，我希望诸位重新回忆与他最后一次相遇的经过。请不要参考其他人的说法。请只写下自己真正记得的事情。  
> 11月2日，雾鸦庄园。  
> 第十三位证人  
> 署名：空白

作用不是集体催眠，而是召集并重新排列真实记忆。误导来自所有人默认“维尔先生”是同一个人、所有回忆都接近案发日。

十三封主邀请函均由阿尔杰农策划书写，爱德华只负责投寄。阿尔杰农从1896年的身份冒认案报道中选中艾薇，把她当作验证骗局的外部校验者。第十三封信夹层里的警告纸条则由奥古斯特放入，笔势与主信不同。

## 十二份证词的三轮解锁

1. **人物证词**：前六份对话/口述；发现记忆冲突，但不知道谁在撒谎。
2. **档案证词**：女仆日记、马车记录、律师信、温室日志；发现日期不一致。
3. **物证证词**：旧照片和钟表维修记录；把身份差异与真实日期连接。

## 六组关键证据

### A｜两只怀表

外观相同、内部维修编号不同，一只属于阿尔杰农，一只属于奥古斯特。证明相同个人物件可被交换；尸体携带的表只能证明“有人放入”，不能单独证明肉身。

### B｜双胞胎旧照片

背面有两个名字，其中一个被墨水覆盖。首次证明庄园隐藏第二个人，并与威廉的摄影记录互证。

### C｜医疗记录

阿尔杰农右手无名指有旧伤和骨骼变形；尸体没有。先推翻“尸体是阿尔杰农”。正向确认奥古斯特采用1889年独立牙医留下的账簿和石膏齿模，以及外部医院记录的左锁骨陈旧骨折，由两名独立医生在验尸官调查中完成比对。

### D｜拿茶杯的习惯

爱德华记得父亲右手拿杯；伊莎贝尔等证词中的“爵士”使用左手。用于识别证词涉及不同兄弟，但习惯可模仿，不能单独承担法律鉴定。

### E｜旧温室痕迹

石阶撞击痕迹、破碎玻璃下血迹、松动湿滑的阶缘和袖口撕痕互证：阿尔杰农夺文件并抓住奥古斯特手腕、袖口；奥古斯特挣脱后退而坠落。没有故意向外推人的动作，但阿尔杰农随后至少四十分钟不求助并处理现场。

### F｜格雷法律档案

1893 年预约簿、签名试写纸、收费收据与埃德蒙·格雷的当日笔记互相校验。笔记记录自称“奥古斯特”的委托人右手无名指无法完全弯曲，试签又与奥古斯特旧样本存在差异。它不能单独证明来客是谁，但与阿尔杰农旧伤病历和签名连续性结合后，可证明幸存者长期以奥古斯特身份生活。

## 推理阶梯

1. **证明有两人**：旧照片＋两只怀表＋封存档案。
2. **推翻尸体身份**：右手旧伤不符＋阿尔杰农医疗档案＋茶杯习惯仅作辅助。
3. **确认尸体是奥古斯特**：牙医账簿/石膏齿模＋独特牙科治疗排列＋左锁骨陈旧骨折＋两名独立医生比对。
4. **确认幸存者是阿尔杰农**：11月1日马车记录＋格雷法律档案＋阿尔杰农旧伤/签名连续性＋爱德华10月27日见面（辅助）。
5. **还原死亡**：温室日志＋血迹/撞击＋最后一封信＋时间与遗体转移记录。
6. **确认策划者**：阿瑟收到的开放顺序＋邀请函纸张/暗记＋阿尔杰农档案笔迹/签名。
7. **W13 完成证词**：爱德华承认 1877 年辨认与 10月27日会面，解释骗局为何并非不可识破。

## 公平性与反漏洞

| 玩家质疑 | 正式解释 |
|---|---|
| 为什么奥古斯特被认成哥哥 | 长期互换；尸体穿阿尔杰农衣服、带其怀表、位于其书房 |
| 阿瑟为何没认出 | 依赖衣着、地点和预设身份，且只知部分旧实验 |
| 爱德华为何没认出尸体 | 未仔细检查，受父亲身份先入认知影响 |
| 医生为何没发现 | 初检缺少完整旧病历且沿用庄园身份；独立鉴定后纠正 |
| 十二证词为何不同 | 不同日期、不同媒介、不同双胞胎或无法辨认 |
| 为什么同时出现 | 阿尔杰农把真实经历编排进同一调查 |
| 为什么留下邀请函 | 让证人重述旧经历，验证骗局能否成立 |
| 为什么选择艾薇 | 阿尔杰农读过她处理身份冒认案的报道，需要最难欺骗的外部调查者为骗局背书 |
| 夹层警告是谁写的 | 奥古斯特发现预封信件后放入；主信仍由阿尔杰农书写 |
| 艾薇为何能破案 | 她核对物证，不接受身份标签 |
| 阿尔杰农为何不是自动等于凶手 | 死亡来自冲突坠落；其未救助与事后犯罪另行判断 |

## 年代边界

- 遗体10月28日至11月1日存放在地下冰窖冷藏间，约4–8°C；11月1日晚移入未生火的书房。低温只延缓腐败，不能让尸体看起来刚死亡。
- 独立鉴定不用DNA、现代指纹数据库或现代影像算法；采用1897年可成立的验尸官调查、旧伤、牙科记录/齿模和外部见证链。
- 格雷档案所用的遗嘱修改程序、事务律师留档习惯与1893年英国法律用语仍需做措辞校验，但不再改变证据功能。
